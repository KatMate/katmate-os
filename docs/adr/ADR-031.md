# ADR-031 — License: GPL-3.0-only, one copyright holder, relicensing kept open until contributions

**Status:** Accepted (2026-10-03, operator ruling R159).
**Related:** `CREDITS.md` (R160), which names the third-party work in
`desktop/`.

**Numbering:** reserved since 2026-08-28 for the GPL-3.0 declaration
covering the CYBRland-derived `desktop/` subtree (ADR-034's numbering note).
This ADR fills the reservation; the decision it records was taken then, and
its scope is now the whole repository.

**Context:**

The repository carried no license file and no license statement: by default
that is all rights reserved, which contradicts the intent to publish it. The
`desktop/` subtree is in part derived from CYBRland (GPL-3.0), so whatever the
project chooses must be compatible with GPL-3.0 for those files. The project
has a single developer, and it accepts no third-party contributions.

**Decision:**

1. **The project is licensed GPL-3.0-only.** The text is the root `LICENSE`,
   the unmodified FSF text of version 3 (sha256 `3972dc97…36986`).
2. **The operator is the sole copyright holder** of the project's own work.
3. **While no third-party contributions are accepted, he may relicense** —
   for example to GPL-3.0-or-later, or to another license.
4. **Before contributions open, a DCO-vs-CLA decision is required.** A DCO
   leaves each contributor the copyright in their contribution, so the
   project could no longer relicense without every contributor's consent.
   Only a CLA preserves the option in 3.

**Consequences:**

- `README.md` states the license and that contributions are not accepted
  yet; `CREDITS.md` names the derived files and their upstream.
- The CYBRland-derived files listed in `CREDITS.md` also carry their upstream
  author's copyright under GPL-3.0. Decision 3 does not reach them: a
  relicensing would need either the upstream's consent or those files'
  replacement.
- Not settled here: `docs/HOST-CONFIG.md` § 9 (the rofi configuration
  source), which ADR-036 names as a provenance question this ADR owns. It
  stays open.
